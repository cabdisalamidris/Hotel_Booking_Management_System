# Hotel Booking Management System

## Project Description

The Hotel Booking Management System is a full-stack web application that enables users to browse hotels, make reservations, and manage bookings. Administrators can manage hotels and bookings through a protected dashboard.

## Features

- User Registration
- User Login (JWT Authentication)
- Hotel Management
- Booking Management
- Admin Dashboard
- Customer Dashboard

## Technologies

### Backend

- Flask
- Flask RESTful
- PostgreSQL
- SQLAlchemy
- Marshmallow
- JWT Authentication
- Flask-Migrate

### Frontend

- React
- Vite
- Axios
- React Router

## Project Structure

Hotel-Booking-Management-System

- backend/
- frontend/

## Installation

### Backend

```bash
cd backend
pipenv install
pipenv shell
flask run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
